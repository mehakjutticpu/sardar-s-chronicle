# Vercel publishing

This website does not require a database or secret keys.

1. Connect the Lovable project to GitHub and import the repository into Vercel.
2. Use Vercel's TanStack Start framework detection and the existing build command (`bun run build` or `npm run build`).
3. Add the Vercel environment variable `NITRO_PRESET=vercel` before deploying; this template defaults to the Cloudflare target otherwise.
4. Publish, then connect your preferred domain. Do not use the private editor preview as the public website.
5. Submit the actual published domain to Google Search Console and request indexing. Create a sitemap with that real domain once available. No placeholder domain is embedded in the site.

Every public page includes its own searchable text, title, description, canonical path, social metadata, and Article structured data identifying the author. Google decides when to index, what to display, and how to rank the site. Meta and Google AI answers are not guaranteed.
